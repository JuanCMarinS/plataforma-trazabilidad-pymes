# Plataforma de Trazabilidad para PYMES

## Descripción del proyecto

Desarrollo de una plataforma web orientada a pequeñas y medianas empresas (PYMES), que permite gestionar y realizar el seguimiento de incidentes y requerimientos relacionados con los servicios tecnológicos.

El sistema busca centralizar la información, facilitar el seguimiento de cada caso y proporcionar indicadores que apoyen la toma de decisiones.

## Objetivo general

Desarrollar una plataforma web para la gestión y trazabilidad de incidentes y requerimientos tecnológicos en pequeñas y medianas empresas.

## Funcionalidades principales

- Inicio de sesión y gestión de usuarios.
- Panel principal con indicadores.
- Registro y consulta de incidentes.
- Seguimiento e historial de incidentes.
- Registro y seguimiento de requerimientos.
- Análisis de datos y estadísticas.
- Generación de reportes.
- Administración de usuarios y roles.

## Tecnologías previstas

- Frontend: Next.js y TypeScript.
- Backend y base de datos: Supabase y PostgreSQL.
- Control de versiones: Git y GitHub.
- Despliegue web: Vercel.

## Metodología de desarrollo

Se utilizará la metodología ágil Scrum para organizar el desarrollo por etapas, realizar pruebas y validar progresivamente las funcionalidades de la plataforma.
